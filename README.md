A collection of data analysis projects in R (tidyverse, ggplot2), each with
R Markdown source and a PDF report.

## Featured
- **[Mammal Sleep Durations](Mammals-Sleep-Durations.pdf)**: sleep duration across
  diets and animal orders (boxplot, ordered dot plot)
- **[Palmer Penguins](Palmer-Penguins.pdf)**: exploratory analysis, faceted plots,
  logistic regression predicting penguin sex

## Other projects
- [Simple Linear Regression](Simple%20Linear%20Regression.pdf): weight vs. height
- [Multiple Regression](Multiple-Regression.pdf): trees and penguins datasets
- [Logistic Regression](Logistic-Regression.pdf): Pima Indians Diabetes
- [T-test](T-test.pdf): life expectancy, Africa vs. Europe (Gapminder)
- [Star Wars Plot](Star%20Wars%20Plot.pdf): height vs. mass with highlighted subgroup

**Tools:** R, R Markdown, dplyr, ggplot2, forcats, palmerpenguins, gapminder
